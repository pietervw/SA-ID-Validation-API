# PHP CheckID API Example

Runnable PHP 8.0+ example using cURL.

## Setup

Ensure the PHP cURL extension is installed, then set your API key:

```bash
export CHECKID_API_KEY="YOUR_API_KEY"
```

## Run

```bash
php checkid-demo.php
```

The script demonstrates single validation, bulk validation, and basic `400`/`401` handling.
